# BPSim

BPSim is a rewrite of Bad Piggies from scratch with *insanely* optimized part rendering pipeline, and with Havok Physics to squeeze out every ounce of performance possible

For example, here is an image of BPSim easily simulating 7000+ metal frames without an issue
