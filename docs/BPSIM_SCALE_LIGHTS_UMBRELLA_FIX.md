# 整车缩放、BPLE 灯具与雨伞修复

日期：2026-11-06。参考：只读 BPLE 2022.1.9 工程及其已编译程序集。

## 整车缩放

进入模拟时原实现按整数网格重新写位置/朝向，没有合成 `PartFreeTransform` 的自由偏移、连续旋转和层深，复制的缩放却仍存在。因此出现部件尺寸缩小而间距回到原网格的现象。

建造更新和模拟入场现在共用 `PartFreeTransform.Compose/VisualScale`。模拟入场先从权威建造数据合成位姿与缩放，再创建刚体/关节；同一帧刚修改的变换也生效。碰撞体继续按自由缩放重建，子实体保留矩阵缩放传播。

## part44 / part45

默认沿用 BPLE B 预设：实体光、特殊雨伞、按方向/连通块分组开启；光反作用力与光触发爆炸属于实验选项，默认关闭。

实体光不再是日志或贴图占位：使用真实网格、原版连续碰撞内核、接触冲量、能量/充能逻辑和可查询的光柱触发碰撞体。正常相连的聚光灯使用实体光，不同时显示旧光锥；单独聚光灯仍保留原光锥收放。停止模拟时清理网格、查询实体、夜视和控制灯改变的碰撞/透明度。

真实照明/夜视可在设置中的「BPLE 夜景照明与夜视」开启。夜视沿用 BPLE 材质的绿色叠加与暗角，而非灰度改色；该效果不作用于非夜景。由于渲染器不同，验收没有宣称所有光照画面逐像素一致。

原版 #5/#6 已存在于 Innovation 模板、图集与物理参数表中，沿用这些资源，没有重复扩充目录。

## part22

- 按下按钮立即触发收放，不再被点击释放/水平拖动拦截；#3/#5 例外：短按松手时收放，水平拖动只调角。
- 按作用方向和连通组件分组；每枚朝向按钮正常蓝底，不再生成第二枚白色角度滑条。
- 默认展开，特殊伞质量 .5，旧模式质量 .2；保留七种原版气阻/角阻尼/锚定/姿态/转向模式。
- 收伞为三次曲线，开伞为六次曲线，严格超过 .25 秒完成；再次按键暂停/恢复同一行程，不重置进度。
- 伞面位置、缩放和碰撞体一起更新，特殊伞面初始化位置回到原版原点。
- 收放完成使用原 BPLE 的两个雨伞音效文件。

## 验收与边界

1. Python 仪器独立解析 BPLE YAML/JSON，与随项目分发的参数资源比对，覆盖 11 灯具和 7 雨伞；检查全部模板键唯一（481）。
2. 在独立 .NET 进程直接执行 BPLE 原程序集纯碰撞方法，与修复后的程序集比较 4,000 个运动用例（193 命中）：零离散差异、最大数值误差 0。独立 A/A 数据 SHA256 一致。
3. Unity Play Mode 完整检查 232 项通过。Unity/原程序集的 4,000 用例零离散差异，最大数值误差约 `1.91e-6`，小于 `1e-4` 判据。
4. 检查包括缩小/放大、同帧位姿/缩放/层深、物理碰撞体尺寸、全部灯具开关/类型/按钮/网格、实际 ECS 冲量与光柱射线、雨伞七模式/质量/动画/碰撞/暂停恢复/分离负例。
