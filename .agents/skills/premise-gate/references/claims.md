# claim 与快照

一次探测 = 一个 claim。机制、普查、性能三类 claim 各有自己的三行。入口在 `SKILL.md` §2.1，仪器侧见 `instruments.md`。

## 机制 claim

`SKILL.md` §2.1 的三行（假设 / 两个互斥预测 / 机器判据）。假设行附**置信度**：

| 级 | 条件 |
|---|---|
| 高 | 关键前提有 L2+ oracle，且已量 A/A 地板 |
| 中 | 有 oracle，未量 A/A |
| 低 | 仅 L1，或只能主观判断 |

置信度描述 claim 本身；结论的可信度按尺度分（`SKILL.md` §5），两者不混用。

## 普查 claim

产出是**覆盖表 / 通过数**而不是真假命题（造仪器、量覆盖率、扫全量语料）时，三行换成：

1. **范围**：覆盖哪个集合（关卡 × 指标）+ **观测单位**（调用点 / 函数入口 / 行 / 采样帧）；明确排除什么（录制不可用、共享日志、随机关卡）。
2. **oracle 版本**：录制/二进制指纹，地面真值来自哪条链路。
3. **判据命令**：一条命令给出逐项二值 + 地板（A/A；量化下限见 `instruments.md` I21）。

普查不产生假设：不写两个互斥预测。预注册行写「范围 + 判据」，跑完状态记 `快照`（`SKILL.md` §8），不写 `已证`。

**先抽样再全量**：全量前在 **3 个单元**上走一遍「快照行」的四条自检钩子；缺一条就不全量。

**阳性对照先行**：从目标集合挑 ≥3 个**必然执行**的单位（脚本 cfunc、每帧回调、启动路径），正式采集里必须 `hit > 0`；全 0 说明仪器或窗口失效，先修仪器。

**未覆盖分三桶报**：`仪器看不见`（结构上不可观测：没有直接调用点、只走虚表/闭包/函数指针、跨模块不可拦）+ `语料没走到`（可观测但路径未覆盖）+ `窗口没覆盖`（执行发生在基线之前/之后或另一个会话：启动、退出、被截断的采集）。三桶下一步不同：换仪器或合成扫描 / 补语料 / 扩窗口。

**观测单位随仪器换**：claim 是「从未执行 / 死代码」时，调用点计数只数直接 `E8`，函数入口计数把闭包、虚表、函数指针都算进来——前者为 0 不能支持后者。

## 性能 / 规模 claim

三行之外另加两条：

1. **热点由 profiler 或采样定位**：微基准只证明「这段能快」，不证明「它是瓶颈」；判据同时钉住输出与时间——同一输入的输出指纹逐字段相同 **且** wall 下降。
2. **并发度 / 线程数 / 批大小实测至少一档**：算术下界不是预测；报告 wall 与总工作量。

## 快照行

`快照` = 覆盖表 / 通过数一类**随构建变化**的测量。行内带构建指纹（二进制 md5 / commit / 语料版本）与四条自检钩子：

1. 语料标识 + 仪器版本；
2. 每个单元的产出非空（`delta > 0`）；
3. 快照边界：基线取在动作**之前**；
4. 观测单位 + 窗口（调用点/入口；启动→退出 / 基线→结束）。

同一范围出了新快照，旧行置 `过期`——台账里只留一行真话。`快照` 里的 0 只读作「本窗口内未观测到」；要支持「从未执行」，用覆盖启动→退出的入口级仪器，并把窗口写进快照。
